Bateria multidomínio do POCO — 2026-11-20
Abra Relatorio.html. Os arquivos CSV usam UTF-8 e a vírgula como separador.
Os resultados do Sonnet são textos finais e contadores da API. Recibos de autonomia conservam nomes de campos, sem valores pessoais do aparelho. O relatório não contém chaves.

Reprodução
1. Use um diretório novo por rodada. rodar.py retoma casos existentes por id e perfil. Exige Python 3, Stockfish acessível pelo PATH e, para Sonnet, o módulo instalado ~/controle-ir/capacidades/tela/piloto.py com a configuração normal da API no aparelho.
2. Na pasta dos casos execute python rodar.py xadrez, python rodar.py sonnet e python rodar.py sonnet --schema. Na coleta original as duas primeiras baterias rodaram em sequência. A última ocorreu posteriormente.
3. Para as missões, envie cada pedido de autonomia_casos.json por executar_capacidade(nome="tela", argumentos={"acao":"missao","texto":pedido}). Não forneça as ferramentas esperadas ao planejador. Meça o tempo completo da chamada e compare a ordem efetiva com o gabarito. Interrupções esperadas não podem executar ferramenta; para os demais casos confira o estado concluída, a sequência e o recibo. A amostra registrada é a série completa de dez casos. Uma coleta interrompida sem registro completo foi descartada.
4. A calculadora é com.miui.calculator. Leia o layout, limpe a entrada e envie uma sequência por expressão, na ordem registrada em calculadora.jsonl. Para rótulos use um passo por tecla; para coordenadas, uma lista de centros obtidos da tela e intervalo de 0,12 s. Solicite elementos ao final e valide o campo atual #result. A navegação inicial e a descoberta de layout foram excluídas das seis medidas.
5. Para recalcular o relatório e os CSV, execute python analisar.py. As quatro famílias podem ser analisadas independentemente. As linhas do tempo usam ms onde indicado.
6. xadrez_casos.json inclui FEN original, jogadas da base e posições já preparadas, incluindo mates imediatos alternativos. A fonte é o CSV público lichess_db_puzzle_sample.csv de aKevinM/Lichess-Puzzles-Analysis (blob Git a02d7a2602f9f492c7134593350e038e2c64b11c). Semente 3200. Entre posições de popularidade ≥80 com ao menos quatro meios-lances no campo Moves, amostramos 8 por faixa, em ordem de PuzzleId antes do sorteio. Novo jogo UCI entre tentativas; respostas adversárias pré-fixadas; ordem dos pares caso/perfil embaralhada. Nenhum lance do gabarito futuro é enviado ao Stockfish.
7. Versão das missões no teste: pacote do commit d4892fe87103687c818aae3122ba6ee9f7cbdc1a do repositório Dialogue-flow. A execução de testes não alterou a configuração de produção.
